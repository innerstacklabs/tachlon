# Code of conduct

This project is a place to build a Gantt chart together. Everyone who takes part in an issue, a pull request or a discussion agrees to the rules below.

## What we expect

- Be kind and direct. Say what you mean in plain words and assume the other person is acting in good faith.
- Criticize the work, never the person. A review comment names the code and the reason.
- Keep to the topic of the project. Politics, personal attacks and advertising for other products do not belong here.
- Accept a decision with grace when the maintainers have made it, and say so plainly if you disagree.

## What is not accepted

- Harassment, insults, threats or discriminatory language, in any form.
- Publishing another person's private information.
- Any conduct a reasonable person would call unwelcome.

## Reporting and enforcement

Tell the maintainers by writing to Dave Remy at the address on his GitHub profile (github.com/daveremy). Reports are private. The maintainers can edit or remove a comment, close a thread, and block a person from the repository, after a warning when the case allows one.

This code applies in every space of the repository: issues, pull requests, discussions and review comments.
