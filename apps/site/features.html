What Tachlon does today

One list of what the chart does, grouped as the vendors group theirs, then a table against Bryntum Gantt, DHTMLX Gantt and Syncfusion Gantt. Each line links the doc it comes from. README links open the public package page on npm; Guide links open the user guide.

Scheduling

  • Four link types (finish-to-start, start-to-start, finish-to-finish, start-to-finish), each with a lag or lead you can edit. Guide
  • The critical path in red, a Critical only filter and a Longest path view. Guide
  • Total float in a column that updates as you edit. Guide
  • The schedule is solved again as you drag, and a note names the tasks the change moved. Guide
  • Date constraints in P6 and MS Project files, from as late as possible to finish no later than, apply to the dates. Guide
  • Working calendars with weekends and holidays, read from the file. Guide
  • A data date you can move: unstarted work cannot start before it. Guide
  • Progress: actual start, actual finish, remaining work and percent complete, rolled up on summary rows. Guide
  • A baseline, variance columns, and filters for tasks that slipped, joined or left the critical path, or lost float. Guide
  • Compare with last month's file: tasks match by ID, and the tasks and links only one file has are listed. Guide
  • The driving path: why a task starts when it does. Guide
  • A lookahead window that keeps only the tasks in the weeks you choose. Guide
  • Summary tasks in an outline you collapse to any level. Guide
  • Milestones: a task with zero duration. Guide
  • Fourteen schedule-check counts, such as missing logic, open ends, leads, lags and high float, with no pass or fail. Guide

Editing

  • Drag a bar to move it, or its right end to change its duration; each is one undo step. Guide
  • Edit names and durations in the list from the keyboard. Guide
  • A task dialog (Shift+Enter, or double-click a bar) for name, duration, dates, progress and remaining work, applied as one undo step. Guide
  • Insert, delete, indent and outdent rows. Guide
  • Add and remove links, and set a link's type and lag. Guide
  • Undo and redo of every edit. Guide
  • Select a range of rows. Guide
  • Paste a list of names as new rows. Guide

Files

  • Open Primavera P6 XER and MS Project XML files, and the chart's own .gantt files. Guide
  • A panel names what a file held that Tachlon did not read. Guide
  • Save as a P6 XER or MS Project XML file, with a list of what the format cannot carry. README
  • Save and reopen the schedule as a .gantt file. Guide
  • Export the list as CSV or an Excel file, or copy it. README
  • Save a PNG picture of the first printed page. README
  • Print to PDF on US Letter or A4 pages, each with a header, page number and legend. Guide
  • Read DHTMLX Gantt and Bryntum Gantt data. README
  • Read plain task and link data, and check it with a named fix for each problem. README

Display

  • Drawn on the GPU, with WebGPU or WebGL2; the 50,000-task timings are in the benchmark. README
  • Zoom from years down to hours, and fit the whole project. Guide
  • Find a task, and filter by a P6 activity code. Guide
  • Choose the list's columns and drag the divider between the list and the chart. Guide
  • Light and dark colors, bar shape, row height and type, set as CSS tokens. README

Languages

  • A locale option sets the chart's language and the style of its numbers. README
  • A texts option puts the buttons, labels and column names in your language. README

Developer API

  • A typed API: the TypeScript declarations cover every method. README
  • A React component. README
  • A Vue 3 component. README
  • An Angular component. README
  • Use from a plain page with no bundler, from a CDN. README
  • Events for select, edit, move, open, load, change and error. README
  • Typed questions to the engine: what-if, why a task starts when it does, schedule health, the critical path. README
  • The engine in Node, with no page, reading P6 and MS Project files. README
  • A JSON Schema of the task data. README
  • npx tachlon init writes a chart file into a Vite or Next.js app. README
  • npx tachlon doctor checks an install and prints a fix for each failure. README
  • Start errors with a code and a fix. README

AI

  • Tool definitions for an assistant, in the MCP, Anthropic or OpenAI form, and callTool to run the one it picks. README
  • An assistant's edit is held as a ghost on the chart for a person to accept or reject. README
  • An AGENTS.md in the package and a llms.txt on this site, for an assistant that installs the chart. README
  • npx tachlon init --skill also writes a short skill file for an assistant. README

How it compares

Vendor pages were read on 2026-11-12, and some again on 2026-11-15 (see docs/features.md). Each vendor cell links a public vendor page, so you can check it; a vendor can change its pages. "Not found" means the vendor's docs and feature pages (linked in the cell) have no page on the topic. Editions are the vendor's own: Bryntum has Community (free, MIT), Core and Enterprise; DHTMLX has Community (free, MIT) and PRO; Syncfusion has one. Tachlon is free and open source under the MIT license, so the table has no cost row. For speed, the benchmark compares only DHTMLX's free edition.
