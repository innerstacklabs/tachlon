Ask your coding assistant to add it.

Paste one prompt into your coding assistant (Claude Code, Codex, Cursor, Copilot), and it installs Tachlon, wires it to your own tasks and links, and mounts the chart. No login, no form, no key.

  1. Install. npx tachlon init finds your framework and bundler and writes a working chart.
  2. Map your data. validate() names every field that does not fit, so the assistant fixes the mapping until it passes.
  3. Fix what breaks. npx tachlon doctor checks the WebAssembly file, your content security policy and the GPU, and gives one fix for each problem.

The skill for Claude Code ships inside the package, and AGENTS.md serves Codex and every other assistant.

Wears your brand.

Every color is a documented token, in light and dark; the bar shape and the type are tokens too. Set them on the chart's box and it looks like your product, not ours.

/* your product's palette */
.gantt {
  --gantt-bg: #ffffff;
  --gantt-text: #1d2433;
  --gantt-bar: #5b4bdb;
  --gantt-crit: #e5484d;
  --gantt-bar-r: 6px;
}

Answers to your code.

Everything the built-in toolbar does is a command you can call, so your own toolbar drives it: every filter, find, outline levels, rows, the data date and the baseline. Read the chart's state, and hear every change.

Load and save as JSON, export P6 XER or Microsoft Project XML, and listen for select, edit, move, load and change events.

chart.on("change", () => {
  const s = chart.state();
  toolbar.render(s.filter, s.rowCount);
});
chart.commands.setFilter("longestPath");
const hits = chart.commands.find("drywall");
